# 경사하강법 실습 코드

`경사하강법_기본수식_학습교안.pdf` 의 실습 코드입니다.

- `경사하강법_실습.ipynb` : Jupyter / Colab 에서 셀 단위로 실행
- `gradient_descent.py` : 한 번에 실행 (`python gradient_descent.py`)

## 준비
```
pip install numpy sympy
```
Colab 에는 이미 설치되어 있습니다. 8장의 lr = 0.25 실험은 일부러 발산시키는 예제라 매우 큰 숫자가 출력되는 것이 정상입니다.
