# 오차역전파 실습 코드

`오차역전파_학습교안.pdf` 의 실습 코드입니다.

- `오차역전파_실습.ipynb` : Jupyter / Colab 에서 셀 단위로 실행
- `backpropagation.py` : 한 번에 실행 (`python backpropagation.py`)

## 준비
```
pip install numpy
```
Colab 에는 이미 설치되어 있습니다. 2~7장 코드는 numpy 없이 순수 파이썬으로 동작하고, 8장 학습 예제만 numpy 를 사용합니다.
