# AI 수학 기초 학습 교안

머신러닝·딥러닝 입문자를 위한 수학 기초 학습 교안과 실습 코드입니다.
테디노트(TeddyNote) 영상 내용을 바탕으로 정리하고, 그림·실습 코드·확인 문제(정답 포함)를 덧붙였습니다.

## 📱 학습 앱: AI 수학 첫걸음

**앱 주소:** https://sinaboro.github.io/ai-math-basics/

교안 3종(기초 수학 · 경사하강법 · 오차역전파)을 **수학 초보자용 모바일 앱**으로 만들었습니다.
폰에 설치하면 앱처럼 아이콘이 생기고, **인터넷 없이도** 공부할 수 있습니다.

| 코스 | 레슨 | 직접 해 보기 (체험 위젯) |
|---|---|---|
| 1. 기초 수학 | 기호 y·ŷ·ȳ, Σ, 평균, 1차·2차 함수, 미분, 편미분, 연쇄법칙 (8개) | Σ 한 단계씩 더하기, w·b 슬라이더 직선, 그릇 모양 2차 함수, 할선→접선 미분, 편미분, 톱니바퀴 연쇄법칙 |
| 2. 경사하강법 | MSE, 손실 그래프, 업데이트 식, MSE 편미분, 학습률, 손계산, 전체 학습 (7개) | 예측 바꿔 손실 보기, w에 따른 손실 그래프, 공 굴리기 경사하강법(발산까지), 30개 데이터 학습 애니메이션 |
| 3. 오차역전파 | 필요성, 계산 그래프·순전파, 로컬 그래디언트, 역전파, 덧셈·곱셈 노드 규칙, 뉴런 학습 (6개) | 순전파·역전파 단계별 계산 그래프, 뉴런 하나 역전파 + 경사하강법 한 걸음 |

- 레슨마다 **핵심 정리**와 **확인 퀴즈**(해설 포함)가 있고, 퀴즈를 모두 맞히면 진도에 기록됩니다.
- **용어 사전**(28개)과 **사용법** 화면이 앱 안에 있습니다.
- 각 코스 화면에서 이 저장소의 **교안 PDF**와 **실습 코드**로 바로 이동할 수 있습니다.

### 설치 방법 (가장 쉬운 방법: 카카오톡)
1. 카카오톡으로 받은 링크 `https://sinaboro.github.io/ai-math-basics/` 를 누릅니다.
2. 앱이 **자동으로 Chrome(아이폰은 Safari)으로 넘어갑니다.** 안 넘어가면 위쪽 안내의 **[Chrome으로 열기]** 를 누릅니다.
3. 화면 위쪽 **"홈 화면에 앱으로 설치하면…"** 안내의 **[설치]** → 확인 창에서 **설치**.
   - 안내가 안 보이면 Chrome **`⋮` → 앱 설치(홈 화면에 추가)**
   - 아이폰은 Safari **공유 버튼 → 홈 화면에 추가 → 추가**
4. 홈 화면에 **Σ AI** 아이콘(AI수학)이 생깁니다. 설치 후 인터넷이 될 때 한 번 열어 두면 비행기 모드에서도 열립니다.

새 레슨이 추가되면 인터넷이 될 때 앱을 열 때 **자동으로 업데이트**됩니다. 진도 기록은 그대로 남습니다.

### 앱 파일 (`docs/` 폴더, GitHub Pages로 배포)
| 파일 | 설명 |
|---|---|
| `docs/lessons.js` | **레슨 내용** (코스·레슨 본문·핵심 정리·퀴즈·용어 사전). 레슨을 고치거나 추가할 때 이 파일을 수정 |
| `docs/app.js` | 화면 이동, 진도 저장, 퀴즈, 체험 위젯, 앱 설치 |
| `docs/index.html` | 화면 틀과 디자인 |
| `docs/sw.js` | 오프라인 캐시. 내용을 고친 뒤에는 `VERSION` 숫자를 올릴 것 (예: `ai-math-v1` → `ai-math-v2`) |
| `tools/make_icons.py` | 앱 아이콘 다시 만들기 (`pip install pillow`) |

레슨 진도는 `"코스/레슨"` 이름(예: `basic/sigma`)으로 저장되므로, 레슨을 추가하거나 순서를 바꿔도 기존 기록이 유지됩니다.
