# AI 수학 기초 학습 교안

머신러닝·딥러닝 입문자를 위한 수학 기초 학습 교안과 실습 코드입니다.
테디노트(TeddyNote) 영상 내용을 바탕으로 정리하고, 그림·실습 코드·확인 문제(정답 포함)를 덧붙였습니다.

## 학습 순서

| 순서 | 교안 | 실습 코드 | 원본 영상 |
|---|---|---|---|
| 1 | [ML_기초수학_학습교안.pdf](ML_기초수학_학습교안.pdf) | [ML_기초수학_실습코드](ML_기초수학_실습코드/) | [#머신러닝 #딥러닝 입문자를 위한 초스피드 기초 #수학](https://www.youtube.com/watch?v=vS51prw_yfw) |
| 2 | [경사하강법_기본수식_학습교안.pdf](경사하강법_기본수식_학습교안.pdf) | [경사하강법_실습코드](경사하강법_실습코드/) | [경사하강법 (Gradient Descent)의 기본 수식에 대해 알려드립니다](https://www.youtube.com/watch?v=GEdLNvPIbiM) |
| 3 | [오차역전파_학습교안.pdf](오차역전파_학습교안.pdf) | [오차역전파_실습코드](오차역전파_실습코드/) | [오차역전파 (Backpropagation)의 개념을 쉽게 이해해 봅시다](https://www.youtube.com/watch?v=1Q_etC_GHHk) |

1. **기초 수학**: 기호(y, ŷ, ȳ), 합계 Σ, 평균, 1차·2차 함수, 미분, 편미분, 합성함수의 미분(연쇄법칙)
2. **경사하강법**: 오차와 MSE, 기울기, w·b 에 대한 편미분, 학습률, 업데이트 식과 파이썬 구현
3. **오차역전파**: 계산 그래프, 순전파, 로컬·글로벌 그래디언트, 덧셈·곱셈 노드 규칙, 역전파 구현

앞 교안의 내용이 다음 교안의 선수 지식이므로 순서대로 공부하는 것을 권장합니다.

## 실습 환경

```
pip install numpy sympy matplotlib
```

각 실습 코드 폴더에는 Jupyter/Colab 용 노트북(`.ipynb`)과 한 번에 실행하는 파이썬 파일(`.py`)이 있습니다.
같은 내용을 압축한 `.zip` 파일도 함께 들어 있습니다.
